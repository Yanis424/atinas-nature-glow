# Atinas — Algerian Natural Dermo-Cosmetics

Static landing page + store (cart and checkout via WhatsApp). No build step — pure HTML/CSS/JS.

## Deploy on Vercel
1. vercel.com → Add New Project → import this repo
2. Vercel auto-detects a static site → Deploy
3. URL: https://atinas-nature-glow.vercel.app

## Customize
- Products: `PRODUCTS` array in index.html
- WhatsApp number for orders: `WHATSAPP` variable in index.html
- All copy is in index.html directly
